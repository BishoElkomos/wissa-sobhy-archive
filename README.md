# أرشيف القمص ويصا صبحي

أرشيف رقمي حي لتوثيق حياة وخدمة القمص ويصا صبحي تادرس، وعلاقاته بالأشخاص والأماكن والأحداث والمصادر والوسائط.

> **الهدف:** ألا تضيع المواد التي جُمعت، وألا نكرر البحث نفسه، وأن تكون كل معلومة قابلة للتتبع والمراجعة.

## المنهج
نربط المعلومات على شكل:

`Person → Role → Institution → Place → Event → Source → Media`

ونفصل دائمًا بين:
- حقيقة موثقة.
- معلومة مؤيدة.
- شهادة شخصية.
- استنتاج/قراءة تحليلية.
- خيط يحتاج تحققًا.
- تعارض بين مصادر.

## قاعدة الاستمرارية
كل جولة بحث أو مادة جديدة يجب أن تتحول إلى أثر محفوظ في GitHub: ملف، تحديث، مصدر، حدث، علاقة، أو خيط بحث محدد.

## سياسة المصادر V3
المصدر المعاصر للواقعة يُفضَّل لإثبات الوقائع المعاصرة، بينما المصدر المتأخر يمكن استخدامه كخريطة لاكتشاف الأصول. لا نعتبر إعادة النشر المتكرر دليل استقلال، ولا نعتبر تاريخ رفع فيديو تاريخ تصويره، ولا نثبت حضور شخص في حدث لمجرد وجود اسمه في سياق المؤسسة نفسها.

## الخصوصية والحقوق
المستودع الحالي **Private**. لا تُنشر مواد شخصية أو صور أو تسجيلات أو وثائق حساسة علنًا دون مراجعة الحقوق والخصوصية.

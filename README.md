
## 🚀 كيفية البدء

### المساهمون المصرح لهم:
```bash
# نسخ المستودع
git clone https://github.com/BishoElkomos/wissa-sobhy-archive.git
cd wissa-sobhy-archive

# تثبيت المتطلبات
npm install

# تشغيل الخادم المحلي
npm start

# بناء الموقع
npm run build

# التحقق من البيانات
npm run validate

# نشر إلى GitHub Pages
npm run deploy
```

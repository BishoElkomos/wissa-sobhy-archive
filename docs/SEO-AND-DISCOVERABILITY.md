# SEO & Discoverability Strategy

## Objective
Make the Wissa Sobhy Archive discoverable as a trustworthy historical reference in Arabic and English while preserving scholarly accuracy and avoiding keyword stuffing.

## Canonical identity
Primary subject:
- Arabic: القمص ويصا صبحي تادرس
- English: Archpriest Wissa Sobhy Tadrous
- Known search variants should be stored as aliases, not separate people.

## Page strategy
High-value indexable pages should include:
- principal biography;
- life/ministry timeline;
- major historical events;
- people and relationships;
- places and churches;
- source records;
- research articles;
- photo/video/audio collections;
- methodology and archive/about pages.

## Internal linking
Every substantial page should link to related people, events, places, institutions, sources and media. Avoid orphan pages.

## Metadata
Every localized page should have unique:
- title;
- meta description;
- canonical URL;
- Open Graph title/description/image;
- language and alternate-language references;
- appropriate structured data.

## Structured data
Use Schema.org only where the entity and content type genuinely fit. Possible types include Person, Article, ImageObject, VideoObject, AudioObject, CreativeWork, WebPage, CollectionPage and BreadcrumbList. Do not manufacture properties that cannot be sourced.

## Multilingual SEO
Arabic and English pages share canonical entity IDs. Use `hreflang` only for genuinely corresponding localized pages. Preserve original-language names and transliterations for discovery.

## Search quality
The archive should rank because it is useful and authoritative: clear historical writing, source provenance, stable URLs, meaningful internal links, fast performance, accessibility, mobile usability and structured data.

## Historical-source SEO
Source pages should expose enough bibliographic metadata for researchers to identify and cite the original publication. Search snippets must never be treated as evidence.

## Image SEO
Where rights permit:
- descriptive file names;
- meaningful captions;
- accurate alt text;
- event/person/place context;
- source and rights metadata.

Do not use misleading alt text to gain search traffic.

## Performance
Prioritize responsive images, modern formats where appropriate, lazy loading for non-critical media, caching and minimal client-side JavaScript. Large archival media should not degrade the initial page experience.

## Sitemap and indexing
Provide XML sitemaps for indexable localized content and media where appropriate. Exclude private, administrative, draft, duplicate and rights-restricted records from public indexing.

## Trust signals
Clearly publish:
- archive ownership/curatorship information;
- methodology;
- source standards;
- correction process;
- copyright/attribution policy;
- contact channel.

## No deceptive optimization
Never create false claims, fake citations, hidden keywords, doorway pages, duplicate language pages, or invented biographical details for SEO.

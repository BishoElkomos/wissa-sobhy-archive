# Media Pipeline

## Principle

Original historical media is preserved separately from optimized public derivatives. Git history is not a media repository.

## Intake

1. Assign an internal asset ID.
2. Preserve the original file and original filename in controlled storage.
3. Record provenance, date precision, place, event, depicted people, creator, rights status, and notes.
4. Create optimized web derivatives.
5. Generate descriptive caption and accessible alt text.
6. Publish only after editorial review and rights review.

## Image derivatives

Prefer modern responsive formats when supported, with a high-quality fallback. Generate multiple sizes for mobile, tablet, desktop, and large editorial display.

## Documents

Preserve the original document separately. Store searchable text/OCR as derived content and clearly label OCR uncertainty.

## Rights

Never infer ownership from possession alone. Record known rights holder, permission status, source, and usage restrictions. If unclear, keep the item private until reviewed.

## Preservation

Maintain checksums or equivalent integrity metadata for original archival files when the production storage layer is implemented.

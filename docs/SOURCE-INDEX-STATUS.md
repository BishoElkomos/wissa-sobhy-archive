## Important source-handling rules
1. Syndicated copies are linked to one canonical article/event rather than counted as independent evidence.
2. Old forum copies are preserved as archival witnesses, especially where they contain images or dates close to the event.
3. Claims are not promoted to fact merely because several sites repeat the same wording.
4. Every person/place/event extracted from a source gets a relationship to that source.
5. Foreign-language coverage is retained even when it only documents the surrounding event rather than Father Wissa personally.
6. Facebook/public social-media material must be treated as a separate source class and preserved with post date, page identity, media, and verification status when accessible.
7. Name collisions are explicitly recorded and excluded from the Father Wissa corpus.

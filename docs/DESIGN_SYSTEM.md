# Design System Direction

## Brand character

Dignified, archival, editorial, contemporary. The interface should feel like a digital museum rather than a generic personal website.

## Visual hierarchy

1. Photography and historical context
2. Strong Arabic typography
3. Dates and archival metadata
4. Source/provenance
5. Supporting navigation

## Palette

Use a restrained palette built around deep navy, warm ivory/paper, muted gold accents, and neutral ink tones. Gold is an accent, not a background or body-text color.

## Components

- Header/navigation
- Hero portrait
- Archive statistics
- Timeline
- Event card
- Person card
- Place card
- Source card
- Media gallery
- Document viewer
- Search interface
- Filter chips
- Breadcrumbs
- Provenance panel
- Related records
- Footer

## Motion

Use subtle entrance and hover transitions only. Respect `prefers-reduced-motion`. Avoid decorative animation that competes with archival content.

## Accessibility

Target WCAG 2.2 AA principles: keyboard navigation, visible focus, semantic headings, sufficient contrast, alt text, reduced motion, clear form labels, and touch targets suitable for mobile.

## Responsive strategy

Mobile-first. Preserve the reading experience on small screens; progressively enhance timelines, galleries, filters, and multi-column layouts on larger screens.

# Entity Disambiguation Standard

## Why this matters
The name Wissa Sobhy appears in different contexts and may refer to different people. The archive must never merge identities because of a name match.

## Minimum matching signals
Before linking a source to the principal subject, compare as many as available:
- full name;
- title/rank at the time;
- church/diocese;
- city/governorate;
- event date;
- age/generation when available;
- family relationships;
- photograph/context;
- named colleagues or institutions;
- source publication context.

## Collision workflow
If a source may concern another person:
1. Create a collision note.
2. Do not attach the source to the principal person.
3. Search for contextual matches.
4. Create a separate entity only when evidence supports a distinct person.
5. Preserve the reason for the separation.

## High-risk identity situations
Apply additional review when a source concerns:
- allegations or accusations;
- criminal/security events;
- sensitive family information;
- political statements;
- photographs with uncertain identification;
- social-media accounts;
- clergy with similar names.

## Public presentation
If ambiguity remains, the public record should say that identification is uncertain rather than silently choosing an identity.

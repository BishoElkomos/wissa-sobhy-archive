# Content Status Workflow

Every archival item moves through a controlled editorial workflow:

`inbox` → `researching` → `source-checked` → `editorial-review` → `published`

Possible exception states:

- `needs-correction`
- `disputed`
- `withdrawn`

## Rules

- Inbox material is not public.
- A source-checked item must have provenance recorded.
- Editorial review verifies dates, names, attribution, links, media rights, and uncertainty labels.
- Published records should remain traceable to the evidence used to publish them.
- Corrections create an audit trail rather than silently erasing the previous state.

# الخصوصية وحماية البيانات | Privacy & Data Protection

**آخر تحديث:** 27 أغسطس 2026

> هذه سياسة تأسيسية تحتاج مراجعة قانونية قبل الإطلاق العام، خصوصًا إذا أصبح الموقع يجمع حسابات أو رسائل أو بيانات تعريفية أو تحليلات تفصيلية.

## 1. مبدأ الخصوصية
الأرشيف التاريخي لا يبرر نشر البيانات الشخصية لمجرد أنها قابلة للعثور عليها. نجمع وننشر الحد الأدنى اللازم لخدمة أغراض التوثيق والبحث، ونميز بين الشخصيات العامة في السياق التاريخي وبين الأفراد الخاصين.

## 2. البيانات التي قد تُجمع
بحسب وظائف الموقع المستقبلية قد تشمل:
- بيانات تقنية أساسية من الخادم أو مزود الاستضافة؛
- بيانات التحليلات إذا فُعلت؛
- الاسم والبريد عند إرسال مساهمة أو تصحيح أو طلب حقوق؛
- محتوى الرسائل والمرفقات التي يرسلها المستخدم طوعًا؛
- تفضيل اللغة وبعض بيانات الجلسة اللازمة للتشغيل.

لا ينبغي جمع بيانات حساسة لمجرد الفضول أو لأغراض لا تتعلق بالمشروع.

## 3. المواد العائلية والشهادات
المعلومات التي تُقدم للأرشيف بوصفها شهادة عائلية أو شفوية يجب أن تحدد حالة الإتاحة: عامة، مقيدة، للاستخدام البحثي فقط، أو غير منشورة. لا تُحوّل الشهادة الخاصة تلقائيًا إلى مادة عامة.

## 4. بيانات الأشخاص الأحياء
يجب تجنب نشر أرقام الهواتف، عناوين المنازل، البريد الشخصي، أرقام الوثائق، بيانات الحسابات، أو أي بيانات شخصية غير لازمة. وإذا كانت هناك حاجة تاريخية مشروعة لذكر معلومة تعريفية، يجب تقييم ضرورتها ومصدرها ودرجة حساسيتها.

## 5. طلبات التصحيح أو الحذف
يمكن للشخص المعني أو صاحب الحق طلب تصحيح بيانات غير دقيقة أو الاعتراض على نشر بيانات شخصية أو طلب تقييدها. لا يعني ذلك أن كل طلب حذف سيُقبل تلقائيًا؛ قد توجد اعتبارات تاريخية أو قانونية أو حقوقية، ويُراجع كل طلب على حدة.

## 6. ملفات تعريف الارتباط والتحليلات
إذا استخدم الموقع Cookies أو أدوات تحليلات أو خدمات خارجية، يجب نشر قائمة محدثة بها والغرض منها وبيانات مزودي الخدمة وآلية التحكم المتاحة للمستخدم. لا نضع أدوات تتبع غير ضرورية قبل تحديد الأساس القانوني والسياسة المناسبة.

## 7. خدمات الطرف الثالث
قد يعتمد الموقع مستقبلًا على الاستضافة أو CDN أو محرك بحث أو تخزين وسائط أو خدمات تحليلات أو بريد إلكتروني. يجب توثيق الخدمات التي تعالج بيانات المستخدمين وتحديث هذه السياسة عند تغيرها.

## 8. أمن المعلومات
يُطبق المشروع مبدأ تقليل البيانات، والصلاحيات المحدودة، وحماية الأسرار، والنسخ الاحتياطية، والتحديثات الأمنية، وعدم تخزين أسرار أو مفاتيح API داخل المستودع العام.

## 9. البيانات التاريخية
المعلومات التاريخية عن أشخاص متوفين أو شخصيات عامة تُعامل مع احترام السياق، لكن لا يُفترض أن كل معلومة قديمة صالحة للنشر. تُراجع المعلومات التي قد تمس أسرًا أو أفرادًا أحياء وفق مبدأ الضرورة والدقة.

## 10. التواصل
تُخصص قناة واضحة لطلبات الخصوصية والتصحيح وحقوق أصحاب البيانات. يجب توثيق الطلبات داخليًا بالقدر اللازم لمعالجتها، وعدم نشر بيانات مقدم الطلب علنًا.

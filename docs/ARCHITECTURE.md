# أرشيف القمص ويصا صبحي تادرس

## الهدف

بناء أرشيف رقمي موثوق، أنيق، قابل للبحث والتوسع، يوثق سيرة القمص ويصا صبحي تادرس ومسيرته الخدمية والمواد المنشورة والوثائق والصور والفيديوهات والأحداث والأشخاص والأماكن المرتبطة به.

## المبدأ الأساسي

الموقع ليس مجرد صفحة سيرة ذاتية. هو **قاعدة معرفة أرشيفية** تربط بين الأشخاص والأحداث والأماكن والمصادر والمواد الإعلامية والوثائق.

## البنية التقنية المستهدفة

- **GitHub:** المصدر الرئيسي للكود، التوثيق، مخططات البيانات، وسجل التغييرات.
- **Next.js + TypeScript:** واجهة الموقع وتطبيق الويب.
- **Vercel:** الاستضافة والنشر الآلي للموقع.
- **Convex:** قاعدة البيانات والوظائف الخلفية والبحث والربط بين سجلات الأرشيف.
- **Object/File Storage:** تخزين الصور والوثائق والملفات الكبيرة خارج Git history عند الحاجة.

## فصل البيئات

هذا المشروع مستقل تمامًا عن أي مشروع آخر في حساب GitHub أو Vercel. أي إعدادات أو مفاتيح أو قواعد بيانات تخص مشروعًا آخر يجب ألا تدخل هذا المستودع.

## مبادئ الأرشفة

1. لا تُضاف واقعة تاريخية باعتبارها حقيقة لمجرد ظهورها في مصدر واحد.
2. كل مادة قابلة للتحقق يجب أن تحمل بيانات المصدر قدر الإمكان.
3. نميز بين تاريخ الحدث وتاريخ النشر وتاريخ رفع المادة إلى الأرشيف.
4. نحتفظ بنسخة من صياغة المصدر في حدود حقوق النشر، ونستخدم الوصف والتحليل بدل نسخ المقالات كاملة.
5. لا نخلط بين الشهادة الشخصية والمصدر الصحفي والمصدر الكنسي والوثيقة الرسمية.
6. المعلومات غير المؤكدة تُوسم بوضوح ولا تُعرض كحقائق قطعية.
7. الصور والوثائق تحفظ مع metadata: التاريخ التقريبي، المكان، الأشخاص الظاهرون، المصور/المالك إن كان معروفًا، المصدر، وحقوق الاستخدام.
8. أي تعديل جوهري في بيانات الأرشيف يجب أن يكون قابلًا للتتبع في سجل التغييرات.

## الطبقات الرئيسية

### 1. Presentation

صفحات عامة عربية أولًا، مع قابلية إضافة الإنجليزية لاحقًا، وتصميم responsive وسريع.

### 2. Archive Data

كيانات منظمة: الأشخاص، الأحداث، الأماكن، المصادر، المقالات، الصور، الفيديوهات، الوثائق، المؤسسات، والخط الزمني.

### 3. Evidence

كل سجل مهم يمكن ربطه بمصدر أو أكثر مع مستوى ثقة وملاحظات تحقق.

### 4. Search & Discovery

بحث عربي قوي، تصفية حسب السنة والنوع والمكان والشخص والمصدر، وصفحات مترابطة تسمح باستكشاف الأرشيف.

### 5. SEO

كل صفحة عامة يجب أن تكون قابلة للفهرسة عند ملاءمة ذلك، مع metadata وcanonical وOpen Graph وstructured data وروابط داخلية وsitemap.
